# V2.3 QQ 数学消息排版

默认展示模式仍是 `plain`。`bot/presentation/plain.py` 只做确定性文字转换，不执行模型返回的 CQ 码、HTML、URL 或本地路径。

已支持的安全转换包括：受保护的代码块、行内代码和 URL；`\(...\)`、`\[...\]`、`$$...$$` 以及可靠的短命令；分数保留括号，根号转为 `√(...)`，常见希腊字母、集合关系、三角函数和上下标转为可复制文字。代码、Windows 路径、金额 `$5` 和未知命令不会通过全局删除反斜杠处理。

模型 token 上限与 QQ 文本分段上限已经分开。输出不再用 token 数当字符数直接切一刀；答案按段落/行边界最多拆为两段，模型 `finish_reason=length` 会明确提示内容可能不完整，超过 QQ 限制时也会明确说明未发送后续部分。

复杂公式 PNG、可信本地产物、渲染隔离容器和 `auto` 模式尚未启用。阶段 4 需要独立的本地渲染器、资源测量和真实截图视觉检查；在此之前保持 plain，不把 PNG 文件存在写成公式图片验收通过。
